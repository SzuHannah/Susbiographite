# Data dictionary

| Folder/file | Purpose |
|---|---|
| `data/foreground_lci/lci_foreground_inventory.csv` | Physical foreground exchanges per 1 kg graphite for BC1/BC2/BO1/BO2, including stage, quantity, unit, and mass-allocation fraction. |
| `data/foreground_lci/lci_allocation_audit.csv` | Exported allocation checks. |
| `data/tea/tea_streams.csv` | Native-unit TEA material/energy/product streams. |
| `data/tea/tea_prices.csv` | TEA material, energy, product, and byproduct prices with references. |
| `data/tea/tea_capex_inputs.csv` | Installed capital inputs by pathway/process area. |
| `data/tea/tea_labour_inputs.csv` | Labour assumptions. |
| `data/tea/tea_financial_assumptions.csv` | Financing, tax, project-life, construction, depreciation, and operating assumptions. |
| `data/prices/electricity_reference.csv` | National industrial electricity baseline 0.0862 USD/kWh and uncertainty bounds. |
| `data/prices/market_reference.csv` | Natural and synthetic graphite market price ranges and means. |
| `data/prices/damage_cost_reference.csv` | Environmental damage-cost low/central/high inputs and provenance. |
| `data/prices/electricity_price_eia.xlsx` | State industrial electricity price source table used by the spatial TEA. |
| `data/prices/feedstock_price_eia.xlsx` | State feedstock price table used by the spatial TEA. |
| `data/market/graphite_impacts_long.csv` | Static market-graphite environmental benchmark results used by sLCC comparisons. |
| `data/spatial/state_source_mapping.csv` | State-to-electricity/diesel/natural-gas region mapping. |
| `data/public_factors/regional_fuel_factors.csv` | Public NETL/EPA diesel and natural-gas regional LCIA factors. |
| `data/factor_templates/lcia_factors_template.csv` | Database-neutral full factor-entry template. |
| `data/factor_templates/regional_electricity_template.csv` | Regional electricity factor-entry template. |
| `reference/paper_results/` | Static paper/reference results used only for validation/comparison. |
